# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is at that link and applies to all project spaces: issues, pull requests,
discussions and any other place where you represent the project.

In short: be respectful and constructive, assume good faith, accept feedback gracefully, and do not
harass, demean or discriminate against anyone.

## Reporting and enforcement

To report unacceptable behaviour, contact the maintainer privately through GitHub (the
[repository owner's profile](https://github.com/DonSosiska); do not use a public issue for this).
Reports are handled confidentially. The maintainer may remove comments, close or lock issues and pull
requests, or block people from the repository, following the enforcement guidelines in the Contributor
Covenant.

Security vulnerabilities are a separate matter: see [SECURITY.md](SECURITY.md).
